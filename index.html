PERGUNTAS FREQUENTES

Perguntas

Como funciona a integração?
Você obtém chaves de API do nosso sandbox, integra os endpoints REST e testa com transações simuladas. Quando estiver pronto, migramos para produção em até 7 dias. Documentação completa, SDKs para Node.js e Python, e suporte direto da equipe de engenharia.
Qual o tempo de settlement?
Em média 3.2 minutos do depósito de stablecoin até a entrega PIX. O processo inclui confirmação on-chain, conversão FX com hedge automático, compliance checks e entrega via PIX instantâneo.
Quais stablecoins são suportadas?
USDC e USDT via Stellar e Ethereum. Suporte a redes adicionais (Polygon, Solana) está no roadmap. Todas as operações são compliance-first com rastreabilidade completa.
Como funciona o hedge automático (NDF)?
Ao criar uma ordem, travamos a taxa FX automaticamente via NDF (Non-Deliverable Forward). Isso protege contra volatilidade cambial durante o período de settlement. Tudo transparente no dashboard.
A ØNSTACK é regulada?
Sim. Operações de câmbio licenciadas pelo BACEN. Compliance automatizado com IOF/IRRF, screening AML via Chainalysis, e relatórios prontos para auditoria. Regulação é core, não add-on.
Quanto custa?
Taxa flat de 0.8% por transação. Sem taxas ocultas, sem spreads variáveis, sem minimum commitments. Volume enterprise? Fale com vendas para pricing customizado.
O que são os rails de RWA?
Real World Assets — ativos tokenizados como recebíveis (FIDC), títulos e instrumentos de dívida. A ØNSTACK está preparada para settlement e custódia desses ativos com compliance regulatório integrado (BACEN + CVM).
Como começar?
Solicite acesso pelo formulário, receba credenciais do sandbox em até 24h, integre a API usando nossos SDKs e documentação, teste com transações simuladas, e migre para produção quando pronto.
